Digit Cards (0–9) — drag a digit into a column or tap a digit, then tap a column

Place Value Grid — the decimal point stays fixed

Move the value using powers of ten

Multiplying makes each digit worth more, so digits shift left. Dividing makes them worth less, so digits shift right. The decimal point does not move.

Editing controls

To change a digit, drag another on top of it. To move it by hand, drag it to a new column. Click a placed digit to select it, then click an empty column.

Teaching note: The powers above each column show its place value. Dragging cards changes their place value; the digit itself stays the same. Light-grey dashed zeros are automatic placeholders; dark digits are the ones you placed yourself. Use the shift controls to model ×10ⁿ and ÷10ⁿ. Operations that exceed the grid range are blocked to avoid hiding digits.
